# Sugestao de post para o LinkedIn

## Versao principal

Acabei de publicar um projeto novo no meu portfolio: AlugaFacil.

O projeto e um sistema web para gerenciamento de aluguel de equipamentos. A aplicacao permite cadastrar usuarios, controlar equipamentos e estoque, criar e acompanhar alugueis e visualizar indicadores da operacao.

Neste projeto pratiquei Node.js, Express, SQLite, JWT, HTML, CSS e JavaScript. Tambem trabalhei com controle de acesso por perfil, relatorios, filtros, metas mensais e um painel executivo com graficos.

Foi uma oportunidade de exercitar o desenvolvimento de uma aplicacao completa, conectando frontend, API e banco de dados em um fluxo real de negocio.
